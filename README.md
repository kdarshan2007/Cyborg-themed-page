# Techfest 2026 · Cyborg Landing Page

A futuristic, single-page landing page concept for **Techfest 2026** at IIT Bombay. It uses a dark interface with orange and teal accents and an animated cybernetic-eye illustration for a technology-focused look.

> **Note:** This is an unofficial frontend project, not an event registration system.

Live demo: https://kdarshan2007.github.io/Cyborg-themed-page/

---

## Features

- Countdown timer to the festival date (16 December 2026)
- Event timeline
- Interactive event-category tabs
- Dark and light themes
- Fully responsive layout for mobile and desktop
- Animated SVG illustration
- Registration button linking to the official Techfest website

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- [Google Fonts](https://fonts.google.com/): Unbounded and Instrument Sans

No framework or build step required. Everything lives in a single file.

## Run locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in Chrome, Edge, Firefox, or any modern browser.

Or serve it with a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/`.

> An internet connection is needed for Google Fonts and any external links.
